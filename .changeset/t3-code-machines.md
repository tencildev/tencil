T3 Code pins can run on another machine. When T3 Code links to other computers (Settings → Labs → Linked environments), the composer shows a machine picker next to the model picker. The thread starts in the same repository on that machine. Tencil signs in to T3 Code's MCP on its own, so there is nothing to set up. Replies from another machine refresh every few seconds, and screenshots stay on this machine.
