Tencil Cloud as an agent for local projects: `npx tencil login` signs the machine in, and after a daemon restart **Tencil Cloud** appears next to T3 Code and Claude Code in a project's settings. Its pins run in a Tencil Cloud sandbox on the branch as it is on GitHub and arrive as a pull request, with the same steps and push status as on previews.
